Change `training-dashboard-ui` · artifact: tasks · follows `design.md` (D-1..D-8) and `specs/app/spec.md`.

## Reconciliation note (spec wins over design D-7)

Design D-7 records each episode's chart duration from a wall-clock `std::time::Instant` and documents pause-inflation as accepted skew. The spec requires the recorded duration to be deterministic and unit-testable: "the completed episode's length in game steps taken from reset to completion" (spec scenario: "an entry holding that episode's final score and step count at completion"). Tasks below follow the **spec**: `end_episode` records `self.game.steps` (captured before `self.game.reset()`), so no `episode_started_at: Instant` field exists and RED test 4 pins exact values. The `EpisodeHistory` ring API (`times: Vec<f32>`, `scores: Vec<usize>`, cap 50) is unchanged from D-7; only the time source differs. Chart 1 title stays "EPISODE TIMES"; its module doc states the series is step-count duration. Verify phase should re-check this call-out (proposal Assumption 3 / design §3 sibling).
